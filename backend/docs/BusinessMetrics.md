# Business Metrics

Example metric names (domain-agnostic framework; names chosen by modules):

- `orders.created`
- `payments.success` / `payments.failed`
- `shipments.created` / `shipments.delivered`
- `warranty.claims`
- `coupon.applied`
- `search.query`
- `recommendation.generated`
- `login.success` / `login.failed`
- `cart.checkout.started` / `cart.checkout.completed`

KPI examples: revenue, order value, refund amount, repair cost, coupon discount, shipping cost.

**Emit only — never aggregate here.**
